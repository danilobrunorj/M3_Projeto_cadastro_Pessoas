📋 M3 Projeto Cadastro de Pessoas

> Um sistema web desenvolvido em Python com Django para o gerenciamento e cadastro de pessoas (CRUD completo).

## 🚀 Sobre o Projeto
Este projeto foi desenvolvido como parte de um módulo de aprendizado (M3), com o objetivo de criar uma aplicação web robusta utilizando o framework **Django**. O sistema permite realizar operações de **C**riação, **R**eitura, **A**tualização e **E**xclusão (CRUD) de registros de pessoas de forma simples e intuitiva.

## 🛠️ Tecnologias Utilizadas
As principais tecnologias e ferramentas utilizadas no desenvolvimento deste projeto:

* **[Python](https://www.python.org/)** (v3.x)
* **[Django](https://www.djangoproject.com/)** (Framework Web)
* **SQLite** (Banco de dados padrão para desenvolvimento)
* **HTML5 / CSS3** (Interface do usuário)

⚙️ Como Executar o Projeto
Siga os passos abaixo para rodar o projeto localmente na sua máquina:

Pré-requisitos
Certifique-se de ter o Python instalado em seu computador.

Passo a passo
Clone o repositório:

Bash
git clone [https://github.com/SEU-USUARIO/M3_Projeto_cadastro_Pessoas.git](https://github.com/SEU-USUARIO/M3_Projeto_cadastro_Pessoas.git)
cd M3_Projeto_cadastro_Pessoas
Ative o ambiente virtual (venv):

No Windows:

Bash
venv\Scripts\activate
No macOS/Linux:

Bash
source venv/bin/activate
Execute as migrações do banco de dados:

Bash
python manage.py migrate
Inicie o servidor de desenvolvimento:

Bash
python manage.py runserver
Acesse no navegador:
Abra o seu navegador e acesse: http://127.0.0.1:8000/
